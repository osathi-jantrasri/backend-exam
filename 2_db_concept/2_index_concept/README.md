### Indexing 

เหมือนกับการทำหน้า Index ท้ายหนังสือเพื่อให้คนหาสิ่งที่ต้องการได้เร็วขึ้น
ทำเพื่อช่วยให้การอ่านข้อมูลเร็วขึ้นแลกกับการเขียนข้อมูลที่ช้าลงและใช้พื้นที่เก็บข้อมูลมากขึ้น 

เนื่องจากการเก็บข้อมูลปกติจะไม่เกิดการเรียงลำดับทำให้เวลาหาข้อมูลต้องหาทั้งหมด O(n) เมื่อมีการจัดเรียงข้อมูลแล้วจะทำให้สามารถหาข้อมูลได้เร็วขึ้นเป็น O(log n)

- ข้อดี 

หาข้อมูลได้เร็ว (SELECT) 

รวมถึงกาเรียงข้อมูลด้วย (ORDER BY, GROUP BY, DISTINCT)

- ข้อเสีย

กินพี้นที่

ทำให้เขียนข้อมูลได้ช้าลง (INSERT, UPDATE, DELETE) เพราะต้องสร้าง Index ใหม่เรื่อยๆ

- การใช้งาน

Cloumn ที่ใช้ WHERE, JOIN, GROUP BY, ORDER BY, DISTINCT บ่อยๆ
